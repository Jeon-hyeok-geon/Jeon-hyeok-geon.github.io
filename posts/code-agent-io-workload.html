RESEARCH NOTE / 001

Measuring tool-execution I/O in coding agents.

A first note on the question, measurement boundary, and evidence level for an ongoing personal research project.

SEPTEMBER 2026 STATUS: IN PROGRESS TOPIC: AI SYSTEMS / STORAGE I/O

The question

Coding agents do more than generate text. They search repositories, read files, apply edits, build code, and run tests. This research asks how those tool-execution paths create I/O at the filesystem and storage-device boundary.

What I am trying to observe

  • Repository exploration and file-read behavior
  • Code edits and the resulting write activity
  • Test and build execution as part of an agent trajectory
  • Differences between process-level and device-level measurements

Current measurement direction

The current workflow brings together syscall traces, process-level measurements, and device counters. Cache state, execution environment, and repeated runs are recorded so that a later comparison can distinguish the workload from avoidable measurement noise.

EVIDENCE LEVEL

The measurement workflow and a cold-versus-warm read pilot have been prepared. A full coding-agent comparison and general performance conclusions are not yet claimed.

What this note does not claim

This is not a published paper, a benchmark result, or a completed performance study. It is a transparent record of an early research direction and the method being prepared to test it.
